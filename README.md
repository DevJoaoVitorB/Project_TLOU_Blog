<h1 align="center"> 🌐 Web Site TLOU Blog</h1>

## 📌 Contexto do Projeto

> 📚 O projeto do **Web Site _TLOU Blog_** foi desenvolvido como parte da disciplina de **Web Design** no curso **Tecnólogo em Análise e Desenvolvimento de Sistemas**, durante o semestre **2024.1**.  
> 💻 A proposta envolveu a **criação de um site completo**, aplicando os princípios de **Design** aprendidos na disciplina e fazendo uso das linguagens:
>
> - 🧱 **HTML5** (estrutura da web)
> - 🎨 **CSS3** (estilização e layout)
> - ⚙️ **JavaScript** (comportamento dinâmico)

---

## 📌 Descrição do Projeto

> 🕹️ O site criado consiste em um **blog temático** focado na franquia 🎮 _The Last of Us_, da empresa **Naughty Dog**.  
> 📢 O objetivo é **informar, entreter e engajar** os fãs, trazendo:
>
> - 📰 Notícias atualizadas  
> - ❓ Curiosidades interessantes  
> - 📚 Informações gerais sobre o universo TLOU
>
> 🌟 O projeto explora não apenas o conteúdo, mas também **a experiência do usuário (UX)** por meio de **navegação intuitiva, layout responsivo e design moderno**.
